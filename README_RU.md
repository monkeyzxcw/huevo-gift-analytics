# Huevo Gift Analytics — бесплатная публикация

## GitHub
1. Создайте репозиторий `huevo-gift-analytics`.
2. Загрузите содержимое этой папки в корень репозитория: `app.py`, `Dockerfile`, `requirements.txt`, `render.yaml`, `static/`.
3. Сделайте commit в ветку `main`.

## Render Free (без платного диска)
1. Подключите репозиторий в Render.
2. Выберите New → Blueprint и выберите этот репозиторий.
3. Убедитесь, что сервис создаётся с планом `free`, затем примените конфигурацию.
4. После успешного deploy откройте выданный HTTPS URL.

## Ограничения бесплатного режима
- Приложение может засыпать при отсутствии посещений.
- SQLite хранится на временной файловой системе: база и история цен могут потеряться при перезапуске, засыпании или redeploy.
- Это тестовый режим, не гарантирующий постоянное хранение данных или непрерывную работу.
- Если Render всё равно требует платёжную карту для вашего аккаунта, не вводите данные карты ради этого проекта; можно выбрать другой хостинг без карты.
- Сборщик обращается к публичным страницам Huevo с паузой между запросами и прекращает работу при HTTP 403/418/429.
