# Huevo Gift Analytics — GitHub + постоянный HTTPS-сайт

## Важно
GitHub хранит код, но не запускает Python-сервер. Для постоянного сайта этот проект настроен на Render как Docker Web Service с постоянным диском для SQLite. План `starter` и постоянный диск являются платными ресурсами; бесплатный web service может засыпать, а его файловая система не гарантирует сохранность SQLite.

## Загрузка на GitHub
1. Создайте на GitHub новый репозиторий, например `huevo-gift-analytics`.
2. Распакуйте архив и загрузите **содержимое папки** в корень репозитория (файлы `app.py`, `Dockerfile`, `requirements.txt`, `render.yaml`, папку `static`).
3. Сделайте commit в ветку `main`.

## Публикация на Render
1. Создайте аккаунт на Render и подключите GitHub.
2. В Render выберите **New → Blueprint** (или New Web Service, если Blueprint недоступен).
3. Выберите репозиторий с проектом и примените настройки из `render.yaml`.
4. Подтвердите создание ресурсов. `render.yaml` задаёт Docker-сервис, HTTPS URL, health-check и постоянный диск `/var/data`.
5. После успешного деплоя откройте URL вида `https://huevo-gift-analytics.onrender.com`.
6. Нажмите «Обновить рынок». Для будущих обновлений Render автоматически пересоберёт приложение после push в GitHub.

## Если создаёте Web Service вручную
- Runtime: Docker
- Health check path: `/health`
- Environment: `HUEVO_DB=/var/data/huevo.db`, `CRAWL_DELAY=2.0`, `MAX_PAGES=500`
- Persistent disk: mount path `/var/data`, размер 1 GB (платный план, если требуется постоянное хранение).
- Auto Deploy: On Commit

## Возможности
- Сбор карточек из публичных HTML-страниц `/market/gifts?page=N`.
- Поиск, сортировка, переход к лоту.
- SQLite: текущие цены и история изменения цен.
- Интерфейс статистики.

## Ограничения
- Сбор с сайта Huevo ещё необходимо проверить после деплоя. Разметка и доступность могут меняться.
- Сборщик прекращает запросы при HTTP 403/418/429; не добавляйте cookie или токены аккаунта в репозиторий.
- Средняя цена — средняя по активным предложениям в собранной базе, не подтверждённая цена продажи.
- Автоматическая покупка не реализована: кнопка ведёт на страницу лота.
- Для постоянного мониторинга нужно нажимать «Обновить рынок»; автоматический планировщик периодических сборов пока не добавлен.
