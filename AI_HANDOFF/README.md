# AI handoff — Huevo Gift Analytics

Эта папка предназначена для следующего ИИ-агента, который должен продолжить разработку существующего проекта.

## С чего начать
1. Прочитай MASTER_PROMPT_RU.md целиком — это основное техническое задание.
2. Прочитай PROJECT_CONTEXT.md — архитектура, автоматизация и подтверждённое состояние.
3. Прочитай KNOWN_ISSUES.md — конкретные дефекты и риски.
4. Прочитай HUEVO_MARKET_RESEARCH.md — исследование HTML маркета и истории сделок.
5. Самостоятельно проверь актуальные файлы, commits, GitHub Actions и Cloudflare deployment. Документация может отставать от кода.

## Главный приоритет
В последнем проверенном CI запуске Python tests завершились ошибкой: 6 тестов crawler ожидали обработку страниц и HTTP-статусов, но получали no_cards и HTTP 200. Browser и Docker jobs этого запуска прошли. Сначала найди первопричину и исправь её, не отключая тесты.

## Безопасность
В чате ранее был вставлен полный Request Headers с cookie, включая session и hchk. Значения намеренно не сохранены здесь. Считай сессию раскрытой: владелец должен инвалидировать/обновить её. Никогда не помещай cookies, токены, Authorization, сырой HAR или личные данные в репозиторий, логи или публичный JSON.

## Критерий существенного завершения
Проект продвинут минимум на 80%, когда красный CI исправлен, все существующие проверки проходят, сбор и деплой подтверждены, документация соответствует реальности, история продаж добавлена безопасно либо её ограничения доказаны, asking prices отделены от completed sales, данные защищены от частичного/повреждённого обновления, а финальный отчёт содержит commits, тесты, deploy status и оставшиеся риски.

Не заявляй, что что-либо проверено или развёрнуто без реального результата.
